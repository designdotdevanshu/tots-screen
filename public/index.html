Install & run

Four ways to start the hub — pick whichever fits your setup.

One-click desktop launchers

No terminal required. Download the project and double-click a single file — the launcher installs dependencies and opens your browser.

1

Download or clone this project to your computer.

2

Windows: double-click start.bat

macOS / Linux: double-click start.sh, or run it from a terminal:

./start.sh
3

Your browser opens on the Sender Studio. Scan the pairing code with your phone and you are live.

Instant run with npx

Nothing to clone or download. If Node.js is installed, run directly from GitHub or NPM.

1

Run directly from GitHub (zero install needed):

npx github:designdotdevanshu/tots-screen --open
2

Or run via NPM package name:

npx tots-screen --open

Docker & Docker Compose

Ideal for a home server, a NAS, or any containerised environment you keep running.

1

Docker Compose — recommended:

docker compose up -d
2

Standalone Docker:

docker build -t tots-screen . && docker run -p 8080:8080 tots-screen

Developer setup (clone & run)

For contributors who want to modify or extend TOTS Screen.

1

Clone the repository:

git clone https://github.com/designdotdevanshu/tots-screen.git && cd tots-screen
2

Install dependencies:

npm install
3

Start the server:

npm start
4

Or start with the browser opening automatically:

npm run dev

Touch gestures

The viewer is built for phones and tablets first.

Pinch to zoom

Two fingers zoom into any region of the shared screen, up to 500%.

Drag to pan

While zoomed in, one finger moves you around the shared display.

Double-tap to reset

Two quick taps snap the zoom level back to fit-to-screen.

Fullscreen

One tap hides the browser chrome for the largest possible picture.

What you get

Everything runs on your machine and your network. Nothing else.

Ultra-low latency

Direct WebRTC peer-to-peer streaming over your LAN, with near-zero delay.

Multi-stream

Broadcast several screens, windows, or tabs at once and let viewers pick a channel.

Private by design

Media never leaves your network. No cloud, no accounts, no telemetry.

Many viewers

Phones, tablets, and laptops watch together — each with independent zoom and pan.

Audio included

Send system or tab audio alongside the picture for complete media streaming.

Zero configuration

No sign-up, no port forwarding, no certificates. Start the server and scan.

Common questions

Connection issues, audio, permissions, and installing the viewer.

Both devices must be on the same Wi-Fi network — not mobile data. Guest and hotel networks usually isolate clients from each other, so use a personal hotspot or your home network instead. Also confirm your firewall allows incoming connections on port 8080.
In the browser's share prompt, pick a browser tab or entire screen and tick “Share audio” at the bottom of the dialog. Window-level audio capture depends on your operating system and browser.
Open System Settings → Privacy & Security → Screen Recording and enable your browser. A browser restart is usually required after granting the permission.
TOTS Screen is built for a shared local network. For remote access you would forward the server port on your router or use a tunnel such as ngrok, cloudflared, or tailscale. Note that WebRTC often needs a TURN server to traverse NAT on remote connections.
iOS (Safari): tap Share → “Add to Home Screen”.
Android (Chrome): tap the three-dot menu → “Install app”.
The viewer then launches as a standalone app icon on your device.
